# Fonts

The same fonts as the card games, the Brand New site and the Matt Rarely Writes blog, so the
sites look alike (copied from card-games/packages/card-kit/src/fonts).
All three are under the SIL Open Font License, Version 1.1; each licence, with its copyright line,
is in the matching `OFL-*.txt`.

- `figtree-latin.woff2`, `figtree-latin-ext.woff2`: Figtree, variable weight 300-900, for text.
  Copyright 2022 The Figtree Project Authors (https://github.com/erikdkennedy/figtree).
- `young-serif-latin.woff2`, `young-serif-latin-ext.woff2`: Young Serif, weight 400, for the logo
  and headings.
  Copyright 2023 The Young Serif Project Authors (https://github.com/noirblancrouge/YoungSerif).
- `dm-sans-600-latin.woff2`: DM Sans, weight 600, Latin subset, used only for the "Support me"
  button, to match Ko-fi's own button.
  Copyright 2014 The DM Sans Project Authors (https://github.com/googlefonts/dm-fonts).
